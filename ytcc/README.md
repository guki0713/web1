# 유튜브 재생목록 자막(CC) 일괄 다운로더

재생목록 주소 하나를 붙여넣으면 그 안의 **모든 영상 자막을 타임라인과 함께** 받는다.
무료, 개수 제한 없음, 중간에 끊겨도 다시 실행하면 이어받는다.
(속은 오픈소스 [yt-dlp](https://github.com/yt-dlp/yt-dlp)를 쓴다.)

## 1. 준비 (처음 한 번)

1. **파이썬 설치** — <https://www.python.org/downloads/>
   윈도우는 설치 첫 화면에서 **"Add python.exe to PATH"** 체크.
2. **이 폴더 받기** — 저장소 페이지 → 초록색 **Code** → **Download ZIP** → 압축 풀기 → `ytcc` 폴더.
3. (권장) **Node.js 또는 Deno 설치** — <https://nodejs.org> · YouTube 쪽 변화에 더 잘 버틴다. 없어도 대부분 동작.

## 2. 실행

| 컴퓨터 | 방법 |
|---|---|
| 윈도우 | `run_windows.bat` 더블클릭 |
| 맥 | `run_mac.command` 더블클릭 (막히면: 우클릭 → 열기, 또는 터미널에서 `bash run_mac.command`) |

검은 창에 `재생목록 주소를 붙여넣고 Enter:` 가 나오면 주소를 붙여넣고 Enter. 끝.
첫 실행은 준비 설치로 1~2분 더 걸린다.

## 3. 결과물

`ytcc/자막/<재생목록 제목>/` 폴더에:

```
0001 영상제목 [영상ID].srt   타임라인 자막 — 플레이어·자막 편집기용
0001 영상제목 [영상ID].txt   [00:01:23] 문장 — 읽기·검색·AI에 넣기용
_전체합본.txt               모든 .txt를 재생목록 순서로 이어 붙인 한 파일
_목록.csv                   영상별 상태(완료/자막 없음/볼 수 없음) — 엑셀로 열림
_진행상황.json              이어받기 기록 (지우면 처음부터 다시)
```

**어떤 자막을 받나** (영상마다 자동 선택):
업로더가 올린 자막 → 없으면 유튜브 자동 생성 자막(영상 원래 언어).
어느 쪽인지는 `.txt` 맨 위와 `_목록.csv`에 적힌다.

## 4. 2000개짜리 재생목록이면

- **시간**: 영상당 약 5~7초 → 2000개 ≈ **3~4시간**. 화면에 남은 예상 시간이 나온다.
  영상 길이(30분이든 3시간이든)는 시간에 거의 영향 없음 — 영상이 아니라 자막 글자만 받기 때문.
- **용량**: 30분 영상 자막 ≈ 20~40KB → 2000개 ≈ 100MB 안팎.
- **끊겨도 됨**: 창을 닫거나 컴퓨터가 꺼져도, 같은 주소로 다시 실행하면 받은 것은 건너뛰고 이어간다.
- 실행 중엔 컴퓨터가 잠자기 모드로 들어가지 않게 해두면 좋다.

## 5. 차단될 때

많이 받으면 YouTube가 잠깐 막는다(`429`, `Sign in to confirm you're not a bot`).
프로그램이 **알아서 1→2→4→8→16→30분 기다렸다 이어간다.** 그래도 계속 막히면 멈추는데, 그때는:

1. 몇 시간 뒤 그냥 다시 실행 (이어받음)
2. 그래도 안 되면 **브라우저 로그인 정보 사용** — 평소 유튜브에 로그인된 브라우저 이름을 붙여 실행
   (명령창 여는 법은 6번):
   ```
   run_windows.bat --cookies-from-browser chrome
   ```
   (`chrome`, `edge`, `firefox`, `whale`, `safari`… 크롬·엣지는 브라우저를 완전히 닫고 실행)
   연령 제한 영상도 이 방법으로 받는다.
3. 대기 시간 늘리기: `--sleep 8`

## 6. 옵션 (필요할 때만)

옵션은 명령창에서 붙인다. 윈도우: `ytcc` 폴더를 연 탐색기 **주소창에 `cmd` 입력 후 Enter** → 열린 창에
`run_windows.bat 옵션`. 맥: 터미널에서 `bash run_mac.command 옵션`.

| 옵션 | 뜻 |
|---|---|
| `--lang ko,en` | 한국어 자막 우선, 없으면 영어. 기본 `orig`(영상 원래 언어) |
| `--translate` | 원하는 언어가 없으면 유튜브 자동 번역 자막이라도 받기 (차단이 더 잦아짐) |
| `--max 5` | 앞에서 5개만 — 처음에 시험해 볼 때 |
| `--retry` | '자막 없음'·'볼 수 없음'으로 기록된 영상도 다시 시도 |
| `--out 폴더` | 저장 위치 바꾸기 |
| `--sleep 초` | 영상 사이 대기 (기본 3초) |

## 7. 알아둘 것

- 자막이 아예 없는 영상(자동 자막도 꺼진 영상, 일부 음악·라이브)은 받을 수 없다 → `자막 없음`으로 기록.
- 비공개·삭제·멤버십 영상은 `볼 수 없는 영상`으로 기록하고 넘어간다.
- 받은 자막은 개인 학습·검색·요약 용도로 쓰고, 재배포는 영상 제작자의 권리를 확인할 것.
- 어느 날 갑자기 전부 실패하면 YouTube가 바뀐 것 — 실행기가 매번 yt-dlp를 최신으로 올리므로 보통 며칠 안에 저절로 해결된다.

## 개발 메모

```bash
python -m unittest ytcc/test_cc_downloader.py   # 오프라인 테스트 (yt-dlp 필요, 네트워크 불필요)
```

`cc_downloader.py` 한 파일 구성: 자막 파서(json3/vtt → 공통 cue) → 트랙 선택(`pick_track`) →
영상 루프(`run`: 상태 기록·차단 대기·이어받기) → 요약 파일.
